# Workforce Scheduling Optimization System

A workforce scheduling project that focuses on creating suitable employee schedules according to availability, skills, working hours, leave requests, rest rules, and shift requirements.

The project explores how AI search techniques and Constraint Satisfaction Problem (CSP) can be applied to workforce scheduling.

---

## 📌 Project Overview

Workforce scheduling is important in organizations such as hospitals, shops, call centres, and factories.

Creating schedules manually becomes difficult when many employees, shifts, and scheduling rules have to be considered together.

The system aims to prepare suitable schedules while reducing conflicts and satisfying important workforce constraints.

---

## ❗ Problem Statement

The project focuses on the following workforce scheduling problems:

- Employee availability
- Shift requirements
- Working-hour limits
- Leave requests
- Rest rules
- Employee skills
- Department staffing requirements
- Multiple departments requiring the same employees

The main objective is to find a suitable schedule while satisfying the required constraints.

---

## 🎯 Objectives

- Understand the limitations of manual workforce scheduling.
- Study AI-based problem-solving techniques.
- Explore search techniques for generating suitable schedules.
- Apply Constraint Satisfaction Problem (CSP) concepts to workforce scheduling.
- Study adversarial search for situations involving competing staffing requirements.
- Identify the information and constraints required for the scheduling system.
- Prepare a conceptual plan for the scheduling system.

---

## 👥 Target Users / Stakeholders

### 👷 Employees
View assigned shifts and provide availability or leave information.

### 👨‍💼 Shift Managers
Prepare and adjust employee rosters according to staffing requirements.

### 🧑‍💼 HR Administrators
Monitor workforce scheduling and manage employee allocation.
